# Public progress publication boundary

Public publication of sanitized ACE-2 milestone summaries was explicitly
authorized on September 6, 2026. This is **documentation and derived evidence
only**, based on already-public `main`; it is not a newer implementation
release or a self-contained executable/reproduction bundle.

The earlier isolated source-remediation branch and its private-metadata
ancestors were **not pushed or merged**. This update imports no newer RTL,
runtime code, broad staged source snapshot, model weights, raw tensor values,
private absolute paths, raw logs or local credentials. Existing public source
remains unchanged. A separately reviewed implementation release is still
required before claiming that these experiments run on public checkout.

- [The progress summary](ACE2_PROGRESS_20260906.md) distinguishes original V74

- [The six-case quality disclosure](CURRENT_LORA176_SOFTWARE_QUALITY_20260906.md)
  preserves all twelve short answers and the negative outcome. Local
  numerical agreement, syntactic readability and a local MAE reduction are
  not useful chatbot quality.
- [Machine-readable provenance](../../evidence/public/ace2-progress-20260906/provenance.json)
  records **original external artifact hashes**, original statuses and typed
  model/checkpoint/source identities. It is a derived summary, not an edited
  acceptance receipt or an assertion that all originals are bundled.
- [Public checksums](../../evidence/public/ace2-progress-20260906/SHA256SUMS)
  bind only the listed **derived published files**. They must not be confused
  with original attempt seals or a verified archive dependency closure.
- Original accepted attempts, input hashes, reviews and report statuses were
  not rewritten or retrospectively promoted. Historical independence
  overclaims carry an explicit causal-RTL-KV-feedback erratum.

## Reproduction limits carried forward

The original V74 path needs matching execution source and its bound BF16
parent, LoRA176 adapter, tokenizer/config, rank1 candidate payloads/reviews,
sealed position-01 verification tree, accepted 24-layer and LM-head inputs,
and original aborted attempt 0001/frontier. V74 uses fixed fresh attempt
0002 and at least 64,800 seconds timeout. These dependencies are not supplied
by this publication. Do not replace their hashes, synthesize missing
receipts, rerun into sealed directories, or substitute a V73 command for V74.

The previous source remediation corrected a missing sidecar build dependency
and new oracle metadata in a separate local snapshot. **Those source changes
are not shipped here.** Nor do the 1021/1100/1128 software candidates modify
this public baseline. Runtime Scale32/packing/RTL support for the new wider
residual profile remains unimplemented.

No new inference, full-model RTL execution, expensive model checks or
original-seal replay was performed to assemble this publication. Only
selected completed reports were read and their summary-file hashes checked.
No in-flight experiment is used as a completed result.

Current scope is local simulation and software analysis. Hardware Stage 2,
FPGA, synthesis, PPA and U280 work is cancelled. Historical Alpha 2/3 hardware
and planning documents remain historical, not current work authorization or
evidence for the newer local execution paths.
